# El cielo en los mitos y el arte

Exposición digital de Julián Cavallo para Introducción a la Programación Web (UAI, 2026).
Reúne relatos y obras sobre el Sol, la Luna y los eclipses, junto con un glosario y una actividad.

## Cómo abrir el sitio

Abrir `index.html` en el navegador o usar Live Server en VS Code.
No requiere instalar dependencias.

## Estructura

- `index.html`: inicio, actividad y fuentes.
- `pages/`: páginas de Sol, Luna, Eclipses, Culturas y Glosario.
- `assets/`: estilos, JavaScript, imágenes y tipografías.

## Estilos y publicación

Las páginas usan `assets/css/site.min.css`. Si se modifican los originales
`styles.css` o `cielo.css`, actualizar también el archivo minificado.

GitHub Pages publica el sitio al subir cambios a `main`.

La tipografía Cormorant Garamond se carga desde Google Fonts.
